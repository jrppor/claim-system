# ระบบเป็น single-tenant ไม่มีตาราง Garage หรือ Insurer

ระบบนี้เป็นของเจ้าของรายเดียวที่เป็นทั้งอู่และบริษัทประกัน จึงไม่สร้างตาราง Garage หรือ Insurer และไม่มีการแยกข้อมูลตามองค์กร (multi-tenancy) ชื่ออู่และชื่อบริษัทประกันเก็บเป็น configuration ใช้แสดงในอีเมลและหัวเอกสาร ผู้ใช้ทุกคนอยู่ใต้เจ้าของเดียวกัน และ Admin จัดการแค่บัญชีผู้ใช้

## Consequences

ถ้าอนาคตต้องรองรับหลายอู่หรือหลายบริษัทประกัน ต้องเพิ่ม tenant key ให้ทุกตารางและทุก query ซึ่งเป็นงานใหญ่ ตัดสินใจรับความเสี่ยงนี้เพราะเป็น prototype
