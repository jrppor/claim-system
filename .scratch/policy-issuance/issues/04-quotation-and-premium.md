# 04: คำนวณเบี้ยและสร้าง Quotation

**What to build:** Underwriter กรอกรถ ชั้นประกัน (1, 2+, 3+, 3) Sum Insured วันเกิดผู้ขับขี่หลัก เลือก Customer เดิมจากอีเมลหรือสร้างใหม่ แล้วได้ Premium พร้อมรายการคำนวณทีละขั้น คำนวณฝั่งเซิร์ฟเวอร์จากตารางอัตราใน DB (seed ค่าเริ่มต้น แก้ด้วยสคริปต์ SQL) ตรวจขอบเขตที่รับได้ (อายุผู้ขับขี่ อายุรถ ช่วง Sum Insured ต่อชั้น) เก็บสแนปช็อตอัตราที่ใช้ อายุ Quotation 30 วัน บันทึกเป็น Quotation แบบ Draft มีเลขที่และประวัติ (Customer ใหม่ยังไม่มีส่วนลด No-Claim Bonus)

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] เบี้ยและรายการคำนวณที่คืนตรงกับค่าที่คำนวณมือจากอัตรา seed ทุกชั้นและค่าที่ขอบ
- [ ] ค่าที่นอกขอบเขตถูกปฏิเสธ 400 พร้อมเหตุผล และไม่รับค่า Premium จาก client
- [ ] แก้อัตราในตารางภายหลังแล้ว Quotation เดิมยังแสดงผลเดิมจากสแนปช็อต
- [ ] เลือก Customer เดิมจากอีเมลหรือสร้างใหม่ได้ ไม่สร้างซ้ำ
- [ ] สิทธิ์: Underwriter เท่านั้น (Admin อ่านอย่างเดียว) และมี If-Match ตามกฎเดิมสำหรับสิ่งที่แก้ได้
- [ ] UI แสดงรายละเอียดการคำนวณทีละขั้นเป็นภาษาไทย; test ผ่าน seam HTTP
