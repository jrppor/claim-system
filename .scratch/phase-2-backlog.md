# Phase 2 backlog (ตัดออกจากเฟสแรก)

ต้องแจ้งผู้ใช้หลังจบเฟสแรกว่ายังมีเรื่องเหล่านี้ต่อ

- อัปโหลดรูปความเสียหาย
- การคำนวณเบี้ยประกัน
- การออกกรมธรรม์ (เฟสแรกใช้ Policy ที่ seed ไว้)
- การชำระเงินจริง
- การเชื่อมระบบภายนอก / ระบบประกันจริง
- integration test ของ SQL/Dapper กับ SQL Server จริง (เฟสแรกใช้ fake repository เท่านั้น ไม่ทดสอบ SQL อัตโนมัติ)
- Redis cache ข้อมูลอ้างอิง (เฟสแรกใช้ Redis แค่ session/refresh token)
