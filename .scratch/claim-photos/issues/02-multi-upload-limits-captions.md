# 02: อัปโหลดหลายรูป เพดาน 20 รูป และคำอธิบาย

**What to build:** อัปโหลดหลายไฟล์ในคำขอเดียว เพดาน 20 รูปต่อ Claim (ถ้ารวมแล้วเกินปฏิเสธทั้งคำขอ ไม่รับบางส่วน) คำอธิบายรูปสั้นๆ ที่ไม่บังคับ และความล้มเหลวกลางทางต้องไม่ทิ้งแถวหรือไฟล์กำพร้า

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] เลือกหลายไฟล์ใน UI ได้ และแต่ละไฟล์ถูกตรวจแยกกัน ไฟล์ผิดหนึ่งไฟล์ทำให้ทั้งคำขอถูกปฏิเสธพร้อมระบุไฟล์นั้น
- [ ] Claim ที่มี 20 รูปแล้วอัปโหลดเพิ่มได้ 409 และคำขอที่ทำให้เกิน 20 ถูกปฏิเสธทั้งหมด
- [ ] คำอธิบายรูปบันทึกและแสดงได้ และมีความยาวจำกัด
- [ ] จำลองความล้มเหลวของการเก็บไฟล์หรือบันทึกแถว ไม่มีแถวหรือไฟล์ค้างใน fake
- [ ] test ผ่าน seam HTTP
